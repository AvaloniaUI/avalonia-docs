### IsValidForInterop Property

Returns true if this OpenGL context is still suitable for interop with the Compositor.
This property might become false in cases like a device loss event on the compositor side.
In that case presentation is no longer possible, however [Avalonia.OpenGL.ICompositionGlContext.GlContext](xref:Avalonia.OpenGL.ICompositionGlContext.GlContext) itself might
still be usable for salvaging user resources. Once the property becomes false, this instance
should be disposed and recreated via
[Avalonia.OpenGL.OpenGlCompositionInterop.TryCreateCompatibleGlContextAsync(Avalonia.Rendering.Composition.Compositor,Avalonia.OpenGL.CompositionGlContextOptions)](xref:Avalonia.OpenGL.OpenGlCompositionInterop.TryCreateCompatibleGlContextAsync%28Avalonia.Rendering.Composition.Compositor%2CAvalonia.OpenGL.CompositionGlContextOptions%29).
A recreated context shares no OpenGL objects with the old one.
