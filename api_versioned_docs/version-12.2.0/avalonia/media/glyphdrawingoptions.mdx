## Remarks

All properties are optional. `null` means "use the font's default" (palette 0
for color glyphs; no bitmap strike preference). Concerns specific to variable fonts
(axis coordinates, named instances) live on [Avalonia.Media.FontVariationSettings](xref:Avalonia.Media.FontVariationSettings).

### PixelSize Property

Gets the optional pixel size used to select a bitmap strike from `sbix`,
`CBDT` or `EBDT` tables.

```csharp
public Nullable<int> PixelSize { get; set; }
```

#### Remarks

When `null`, no bitmap strike is selected and the font's outline (or
color-layer) representation is used instead.

#### Exceptions

- [Set to a value less than 1.](xref:System.ArgumentOutOfRangeException)
