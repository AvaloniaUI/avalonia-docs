### FontVariation Constructor

A single variation axis setting in designer units, e.g. `wght = 700`.

```csharp
public FontVariation(Avalonia.Media.Fonts.OpenTypeTag Tag, double Value)
```

#### Parameters

`Tag` [Avalonia.Media.Fonts.OpenTypeTag](xref:Avalonia.Media.Fonts.OpenTypeTag)

The OpenType axis tag (e.g. `wght`, `wdth`, `opsz`).


`Value` double

The axis position in the font's user coordinate space — the same units the font's
`fvar` table declares for the axis (weight 100–900, width percentages, optical
sizes in points). Values are clamped to the axis range and normalized per font when
the settings are applied; axes a font does not declare are ignored.
