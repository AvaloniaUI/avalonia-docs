## Remarks

Variation axes are the design dimensions a variable font exposes — typical examples
include `wght` (weight, 1..1000), `wdth` (width, percentage), `opsz`
(optical size, points), `ital` (italic, 0..1), and `slnt` (slant, degrees).

Values are in user-space: the same values the font designer chose to expose to
end users (e.g. weight `700` for "Bold"). The platform-neutral
[Avalonia.Media.FontVariationSettings](xref:Avalonia.Media.FontVariationSettings) also speaks user-space values; they are
normalized into `[-1, 1]` through the font's `fvar` / `avar` tables
per font when the settings are applied.
