## Remarks

Named instances are pre-defined points in variation space the font designer has
labeled — for example "Regular" at `wght=400`, or "Light Condensed" at
`wght=300, wdth=75`. They give applications a curated set of preset combinations
without having to invent their own.

Coordinates are in user-space (the same values the font designer chose to
expose) — the same space [Avalonia.Media.FontVariationSettings](xref:Avalonia.Media.FontVariationSettings) speaks, so an
instance's coordinates translate directly into settings values. Normalization to
the font's internal coordinate space happens when the settings are applied.
