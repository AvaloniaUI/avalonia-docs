## Remarks

This event is raised when the user drops a dragged column header at a new position, before
the column is moved. Setting [Avalonia.Interactivity.CancelRoutedEventArgs.Cancel](xref:Avalonia.Interactivity.CancelRoutedEventArgs.Cancel) to true prevents
the move.
