### Delete Method

Deletes the selected content, then collapses the selection to the

```csharp
public Avalonia.Controls.Documents.TextModel.TextPointer Delete()
```

#### Returns

[Avalonia.Controls.Documents.TextModel.TextPointer](xref:Avalonia.Controls.Documents.TextModel.TextPointer)

The deletion-point pointer returned by the base operation.


#### Remarks

The base [Avalonia.Controls.Documents.TextModel.TextRange.Delete](xref:Avalonia.Controls.Documents.TextModel.TextRange.Delete) returns the deletion point but
does not reset `_isForwardSelection` or re-anchor the selection, so
cut used to resolve the caret to the wrong endpoint. Re-selecting the
returned pointer fixes every delete/cut entry point.

</section>

### InsertSnapshot Method

Inserts a document snapshot over the selection, then collapses the
selection to the end of the inserted content and resets direction.

```csharp
public void InsertSnapshot(Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot snapshot)
```

#### Parameters

`snapshot` [Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot](xref:Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot)

The snapshot whose tree is grafted into the selection.


#### Remarks

The base [Avalonia.Controls.Documents.TextModel.TextRange.InsertSnapshot(Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot)](xref:Avalonia.Controls.Documents.TextModel.TextRange.InsertSnapshot%28Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot%29) leaves the range spanning
the grafted content and never touches selection direction, so paste used
to leave a non-collapsed selection whose caret sat one line past the
content. Collapsing here re-anchors the caret the same way keyboard edits
do via [Avalonia.Controls.TextSelection.MoveTo(Avalonia.Controls.Documents.TextModel.TextPointer,bool)](xref:Avalonia.Controls.TextSelection.MoveTo%28Avalonia.Controls.Documents.TextModel.TextPointer%2CSystem.Boolean%29), fixing every paste entry point (toolbar
actions and keyboard).
