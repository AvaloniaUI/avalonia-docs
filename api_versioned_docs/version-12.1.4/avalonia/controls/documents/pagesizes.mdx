## Remarks

Named sizes are portrait; [Avalonia.Controls.Documents.PageSizes.Landscape(Avalonia.Size)](xref:Avalonia.Controls.Documents.PageSizes.Landscape%28Avalonia.Size%29) turns one on its side. Note the
unit trap these names exist to avoid: PDF and print software often quote paper in
points (1/72 inch) — US Letter is 612 × 792 points but 816 × 1056
device-independent pixels.
