## Remarks

[SnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode) is designed for serialization scenarios (RTF/HTML export, autosave).
It captures a point-in-time view of the document structure.

Memory per node varies by subtype:
- Base: ~64 bytes (Kind, offset, length, children)
- [InlineSnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.InlineSnapshotNode): +32 bytes ([InlineFormatting](xref:Avalonia.Controls.Documents.TextModel.Formatting.InlineFormatting))
- [BlockSnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.BlockSnapshotNode): +32 bytes ([BlockFormatting](xref:Avalonia.Controls.Documents.TextModel.Formatting.BlockFormatting))
- [HyperlinkSnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.HyperlinkSnapshotNode): +8 bytes (URI reference)
- [ListSnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.ListSnapshotNode): +12 bytes (marker style + start index)
- [ImageSnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.ImageSnapshotNode): +48 bytes (image data + metadata)
For typical documents (100 pages, ~5000 nodes), snapshot size is ~400-600 KB.

### FormatMetadata Property

Format-specific metadata for round-trip fidelity.
Serializers (RtfWriter, DocxWriter, etc.) can attach format-specific state here
to preserve information that doesn't map cleanly to the semantic snapshot model.
Not thread-safe; single-threaded access only.

```csharp
public object FormatMetadata { get; set; }
```

#### Remarks

Example: RTF uses twips for measurements and has 15 border types. The snapshot
uses DIPs and 5 semantic border styles. Format metadata preserves original values
for perfect round-trip fidelity.

The raw slot is internal: [Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode.GetFormatMetadata&lt;T&gt;](xref:Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode.GetFormatMetadata%60%601) and
