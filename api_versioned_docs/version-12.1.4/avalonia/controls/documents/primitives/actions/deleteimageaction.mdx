## Remarks

Enabled only when an image is the current context (see
[Avalonia.Controls.Documents.Primitives.BlockContextResolver.GetContextImage(Avalonia.Controls.Documents.Primitives.ITextEditorHost)](xref:Avalonia.Controls.Documents.Primitives.BlockContextResolver.GetContextImage%28Avalonia.Controls.Documents.Primitives.ITextEditorHost%29)). Deleting and undoing
restores the image whole. Removal goes through
[Avalonia.Controls.Documents.TextModel.TextDocument.DeleteNode(Avalonia.Controls.Documents.TextModel.TextDocumentNode)](xref:Avalonia.Controls.Documents.TextModel.TextDocument.DeleteNode%28Avalonia.Controls.Documents.TextModel.TextDocumentNode%29) so the image node is detached
cleanly — a character-range delete would strip the object character but
leave a zero-length orphan node behind.
