## Remarks

A null [Avalonia.Controls.Documents.TextModel.Formatting.InlineFormatting.UnderlineStyle](xref:Avalonia.Controls.Documents.TextModel.Formatting.InlineFormatting.UnderlineStyle) means unset and draws as
[Avalonia.Controls.Documents.TextModel.Formatting.UnderlineStyle.Single](xref:Avalonia.Controls.Documents.TextModel.Formatting.UnderlineStyle.Single). Null stays distinct from an explicit [Avalonia.Controls.Documents.TextModel.Formatting.UnderlineStyle.Single](xref:Avalonia.Controls.Documents.TextModel.Formatting.UnderlineStyle.Single) so that
merging formatting down an inline chain keeps the `child ?? parent` idiom: an unset child
takes the ancestor's style, while a child that says [Avalonia.Controls.Documents.TextModel.Formatting.UnderlineStyle.Single](xref:Avalonia.Controls.Documents.TextModel.Formatting.UnderlineStyle.Single) overrides it.

The values cover the underline variants RTF and DOCX can express, so a document that carries
one survives an edit instead of degrading to a plain underline.
