### AnnotationError Event

Raised when an annotation operation fails — adding, editing or deleting an annotation.

```csharp
public event EventHandler<Avalonia.Controls.PdfAnnotationErrorEventArgs> AnnotationError
```

#### Remarks

The user has already acted by the time this fires (drawn a shape, pressed Delete), so a
failure is silent from their point of view unless the host surfaces it. The message is
also written to [Avalonia.Controls.PdfViewer.ErrorMessage](xref:Avalonia.Controls.PdfViewer.ErrorMessage), so binding that is enough for simple hosts;
handle this event when you need the [Avalonia.Controls.PdfAnnotationErrorEventArgs.Operation](xref:Avalonia.Controls.PdfAnnotationErrorEventArgs.Operation)
or the underlying exception.
