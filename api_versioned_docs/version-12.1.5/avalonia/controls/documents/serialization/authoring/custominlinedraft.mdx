### InsertObjectReplacementCharacter Property

When `true`, an object replacement character (U+FFFC) is inserted
into the text stream during document building, giving this inline a
non-zero length so the rendering pipeline can discover it.
Set this for embedded objects (images, etc.) that have no text content.
