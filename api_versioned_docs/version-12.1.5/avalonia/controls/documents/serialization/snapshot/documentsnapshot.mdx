## Remarks

[DocumentSnapshot](xref:Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot) captures a point-in-time view of the document including:
- Text content (via immutable RopeNode reference)
- Tree structure (copied as [SnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode) tree)
- Formatting (captured as value types)

Thread-safety is achieved through snapshot isolation:
- Text storage uses immutable functional rope nodes
- Structure is copied at snapshot time
- Formatting is stored as value types (no shared references)

Typical use:

```csharp
// On UI thread:
var snapshot = document.CreateSnapshot();

// On background thread:
await Task.Run(() => serializer.Serialize(snapshot, stream));
```
