<div className="apiref-page__lead">

A [Avalonia.Controls.Documents.RichImageSource](xref:Avalonia.Controls.Documents.RichImageSource) whose encoded pixel bytes are embedded in the
document. Decodes once from the retained bytes, caches and owns the decoded
bitmap, and reports the intrinsic size from the image header without a full
decode. Dispose to release the cached bitmap.
