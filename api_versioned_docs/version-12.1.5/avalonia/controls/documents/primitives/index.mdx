- [CaretElement](caretelement.mdx) - Renders the text caret (insertion point) in the editor.

Editor-specific extensions live in the `EditorTextView` subclass.

fields resolve per page.
- [PagedTextView](pagedtextview.mdx) - A text view that lays the document out as discrete pages (Word's print layout): blocks
fill page bands until the page content height is reached or a page break forces a new
page, page sheets render behind the content, and the placement seams of
[Avalonia.Controls.Documents.Primitives.TextViewBase](xref:Avalonia.Controls.Documents.Primitives.TextViewBase) are answered from a break table so the anchored
virtualization, extent, and scrollbar projections work unchanged.
- [TextLineInfo](textlineinfo.mdx) - A lightweight struct representing line information for caret positioning and navigation.
Implements [Avalonia.Controls.Documents.Primitives.ITextLine](xref:Avalonia.Controls.Documents.Primitives.ITextLine) as a value type to avoid allocations.
- [TextViewBase](textviewbase.mdx) - A virtualizing text view that only realizes document blocks overlapping the viewport.
Implements [Avalonia.Controls.Documents.Primitives.ITextView](xref:Avalonia.Controls.Documents.Primitives.ITextView) for coordinate mapping and [Avalonia.Controls.Primitives.ILogicalScrollable](xref:Avalonia.Controls.Primitives.ILogicalScrollable)
to drive a parent [Avalonia.Controls.ScrollViewer](xref:Avalonia.Controls.ScrollViewer).
- [VirtualizingContentHost](virtualizingcontenthost.mdx) - A lightweight [Avalonia.Controls.Control](xref:Avalonia.Controls.Control) whose children are measured and arranged
externally by [Avalonia.Controls.Documents.Primitives.TextViewBase](xref:Avalonia.Controls.Documents.Primitives.TextViewBase). Its own
[Avalonia.Controls.Documents.Primitives.VirtualizingContentHost.MeasureOverride(Avalonia.Size)](xref:Avalonia.Controls.Documents.Primitives.VirtualizingContentHost.MeasureOverride%28Avalonia.Size%29)/[Avalonia.Controls.Documents.Primitives.VirtualizingContentHost.ArrangeOverride(Avalonia.Size)](xref:Avalonia.Controls.Documents.Primitives.VirtualizingContentHost.ArrangeOverride%28Avalonia.Size%29) are intentional

measure/arrange pass driven by [Avalonia.Controls.Documents.Primitives.TextViewBase](xref:Avalonia.Controls.Documents.Primitives.TextViewBase).
