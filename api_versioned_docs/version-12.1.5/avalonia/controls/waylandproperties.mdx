### AppIdProperty Field

```csharp
public Avalonia.AttachedProperty<string> AppIdProperty
```

#### Remarks

Specifies the application ID (`app_id`) sent to the Wayland compositor via `xdg_toplevel`
for window management, application identification, and window grouping.

In Wayland environments, client windows do not directly provide their own window icons. Instead,
compositors, docks, and taskbars resolve the application icon, launcher identity, and notifications by
matching the `AppId` against the filename of the application's installed `.desktop` file
(for example, using `org.example.myapp` to match `org.example.myapp.desktop`).
