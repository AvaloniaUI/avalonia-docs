## Remarks

Exposes the [TreeDataGrid](xref:Avalonia.Controls.TreeDataGrid) to UI Automation clients (screen readers and other assistive
technologies) as a data grid. The peer surfaces the selection and scrolling patterns; the
individual rows, cells and column headers are exposed by their own peers.
