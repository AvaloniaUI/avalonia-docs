## Remarks

Actions are organized by category:

- Edit actions: Undo, Redo, Cut, Copy, Paste, SelectAll
- Format actions: Bold, Italic, Underline, Strikethrough, Superscript, Subscript
- Font actions: [FontFamily](xref:Avalonia.Media.FontFamily), FontSize, ForegroundColor, BackgroundColor

Use these instances in XAML with `{x:Static editor:EditorActions.Bold}` or
access them from code via `EditorActions.Bold`. [Avalonia.Controls.Documents.Primitives.Actions.EditorActionIds](xref:Avalonia.Controls.Documents.Primitives.Actions.EditorActionIds)
carries the matching [Avalonia.Controls.Documents.Primitives.Actions.IEditorAction.Id](xref:Avalonia.Controls.Documents.Primitives.Actions.IEditorAction.Id) for [Avalonia.Controls.Documents.Primitives.Actions.EditorActions.GetById(string)](xref:Avalonia.Controls.Documents.Primitives.Actions.EditorActions.GetById%28System.String%29).
