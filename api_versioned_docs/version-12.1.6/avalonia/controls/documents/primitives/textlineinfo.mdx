### ContainingElement Property

Gets the node whose content this line belongs to, if any. Selection
rendering and vertical navigation group lines by it, so a line that
reports none is skipped by both.

```csharp
public object ContainingElement { get; set; }
```

#### Remarks

Defaults to so a line written before this member existed
still compiles. Such a line is skipped by selection rendering and by vertical
navigation, which is the same treatment it received before the member was added.
