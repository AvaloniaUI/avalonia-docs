<div className="apiref-page__lead">

Describes where a [Avalonia.Controls.Documents.RichImage](xref:Avalonia.Controls.Documents.RichImage)'s pixels come from and how they
are obtained. Embedded sources carry their encoded payload in the document
and decode synchronously; deferred sources resolve asynchronously (e.g. from
a URL via a loader) and only when the image is actually presented.

## Remarks

A [Avalonia.Controls.Documents.RichImageSourceConverter](xref:Avalonia.Controls.Documents.RichImageSourceConverter) lets a source be authored in XAML from
an absolute URI string, e.g. `Source="avares://MyApp/Assets/picture.png"`.

### ResolveAsync Method

Resolves the decoded image. Embedded sources complete synchronously;
deferred sources fetch/decode in the background. Returns
when the image cannot be produced. Callers must not
dispose the returned image — its lifetime is owned by the source (or its
loader); a source that owns a decoded bitmap implements [IDisposable](xref:System.IDisposable).
