<div className="apiref-page__lead">

A [Avalonia.Controls.Documents.RichImageSource](xref:Avalonia.Controls.Documents.RichImageSource) backed only by decoded pixels (a
[Avalonia.Controls.Documents.Imaging.PixelHolder](xref:Avalonia.Controls.Documents.Imaging.PixelHolder)), with no encoded payload — for images created from raw
pixels in code (e.g. a `WriteableBitmap`). Capture carries the pixel buffer
into the snapshot, and serializers re-encode it to a supported format. Renders by
building a bitmap from the pixels, which this source owns and disposes.

</div>
