<div className="apiref-page__lead">

A text view that lays the document out as discrete pages (Word's print layout): blocks
fill page bands until the page content height is reached or a page break forces a new
page, page sheets render behind the content, and the placement seams of
[Avalonia.Controls.Documents.Primitives.TextViewBase](xref:Avalonia.Controls.Documents.Primitives.TextViewBase) are answered from a break table so the anchored
virtualization, extent, and scrollbar projections work unchanged.

## Remarks

Pagination is sequential (a block's page depends on every height before it), so the
break table is filled by an idle-time dispatcher pass that measures blocks at the page
content width — realized blocks reuse their measurement, others are measured through a
transient node and recycled immediately. [Avalonia.Controls.Documents.Primitives.PagedTextView.PageCount](xref:Avalonia.Controls.Documents.Primitives.PagedTextView.PageCount) grows while the pass
runs; blocks beyond the table lay out packed until it catches up.

V1 places whole blocks: a block taller than the remaining page moves to the next page,
and a block taller than a full page overflows its own page. Splitting blocks across
pages (paragraph lines, table rows) is the fragmentation stage of the paged layout
plan.

### PageBandDistance Property

Gets or sets the distance from the sheet edge to a page band: the header's top
sits this far below the sheet top, the footer's bottom this far above the sheet
bottom (Word's header/footer distance). A band is clipped to the margin area.

```csharp
public double PageBandDistance { get; set; }
```

#### Remarks

The value belongs to the document
([Avalonia.Controls.Documents.FlowDocument.PageBandDistance](xref:Avalonia.Controls.Documents.FlowDocument.PageBandDistance)) and this property is a handle on it:
setting it writes through, and it follows the document when the document's value
changes. A band taller than the space it leaves pushes the body down, so the
distance decides where pages break and print and PDF export must resolve the same
one - a copy kept per view would break the same document on different lines.
