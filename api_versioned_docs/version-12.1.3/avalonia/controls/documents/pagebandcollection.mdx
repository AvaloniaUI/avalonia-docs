<div className="apiref-page__lead">

The page bands a document owns, as elements: a view over the text document's
[Avalonia.Controls.Documents.TextModel.TextDocument.PageBands](xref:Avalonia.Controls.Documents.TextModel.TextDocument.PageBands), which owns the bands, materializing a
[Avalonia.Controls.Documents.PageBand](xref:Avalonia.Controls.Documents.PageBand) element per band on demand. It follows the contract of the
block collection: the document becomes a band's logical parent the moment it is
added; while the document has no text document the band waits pending, and it
joins the text document when that is initialized, before the pending blocks
materialize; once the text document exists a band joins it at once. Removing a band
releases owner, logical parent and undo and clears every section reference to it.
Ownership is exclusive: a band owned by another document is refused until it is
removed there. The first band with a given role and rule is the one the rule places.
