<div className="apiref-page__lead">

A page-number field: an inline that stands for the current page number or the
total page count, primarily inside a [Avalonia.Controls.Documents.PageBand](xref:Avalonia.Controls.Documents.PageBand). The number depends on
pagination - the same band renders on every page with a different one - so nothing
numeric is stored: the field occupies a single object replacement character and
rendering resolves it against the page it lands on. Layout with no pages at all
reads as a single page. The field edits as one atomic unit.
