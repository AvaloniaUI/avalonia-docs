## Remarks

A relative URI is resolved against the XAML base URI of the document being loaded,
the same way [Avalonia.Media.FontFamily](xref:Avalonia.Media.FontFamily) and Avalonia's `Image.Source`
resolve relative asset references. Local assets (`avares:`/`resm:` via the
asset loader, or `file:` from disk) are read immediately and embedded as an
[Avalonia.Controls.Documents.EmbeddedImageSource](xref:Avalonia.Controls.Documents.EmbeddedImageSource), so the pixels travel with — and serialize with —
the document. Remote images (`http:`/`https:`) become a
[Avalonia.Controls.Documents.DeferredImageSource](xref:Avalonia.Controls.Documents.DeferredImageSource) that records the URL; the editor shows a placeholder
until a loader resolves it. The MIME type is inferred from the file extension.
