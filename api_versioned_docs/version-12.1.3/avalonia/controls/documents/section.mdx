### Header Property

Gets or sets the section's header for every page the other selectors do not
claim. A reference to a [Avalonia.Controls.Documents.PageBand](xref:Avalonia.Controls.Documents.PageBand) the owning document holds in
[Avalonia.Controls.Documents.FlowDocument.PageBands](xref:Avalonia.Controls.Documents.FlowDocument.PageBands): one band can serve any number of
sections. A section without a reference falls back to the document root's for
the same selector. Setting an unowned band adopts it into the owning document
(when the section attaches, if it is detached now); a band owned by another
document is refused. Null clears the reference. Layout consults top-level
sections only.
