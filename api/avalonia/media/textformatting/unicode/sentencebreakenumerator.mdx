## Remarks

The enumerator is a operating on a [ReadOnlySpan&lt;T&gt;](xref:System.ReadOnlySpan%601)
so every operation is allocation-free. It reads codepoints with
[Avalonia.Media.TextFormatting.Unicode.Codepoint.ReadAt(ReadOnlySpan&#123;char&#125;,int,int@)](xref:Avalonia.Media.TextFormatting.Unicode.Codepoint.ReadAt%28System.ReadOnlySpan%7BSystem.Char%7D%2CSystem.Int32%2CSystem.Int32%40%29) and classifies them via the [Avalonia.Media.TextFormatting.Unicode.SentenceBreakClass](xref:Avalonia.Media.TextFormatting.Unicode.SentenceBreakClass)
property backed by the `SentenceBreak` trie. Each codepoint is visited a constant
number of times: the left-hand context every rule needs is folded into a few fields as the
walk advances, and the one rule that looks ahead reuses the scan it already made.
