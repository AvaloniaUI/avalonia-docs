### Modifiers Property

Gets the modifier state.

```csharp
public Nullable<ulong> Modifiers { get; set; }
```

#### Remarks

Win32: console `dwControlKeyState` flags (LEFT_CTRL_PRESSED, RIGHT_ALT_PRESSED, ENHANCED_KEY, ...),
including the key being pressed.
X11: `XKeyEvent.state`, the state before the event.
Wayland: the effective XKB modifier mask, the state before the event.
macOS: `NSEventModifierFlags`.
Only the core XKB modifiers (Shift, Lock, Control, Mod1 to Mod5) have fixed bits. What Mod1 to Mod5 mean
depends on the XKB keymap.

</section>

### ScanCode Property

Gets the scan code of the key.

```csharp
public Nullable<uint> ScanCode { get; set; }
```

#### Remarks

Win32: the hardware scan code, plus 0xE000 for extended keys.
X11 and Wayland: the XKB keycode (evdev code + 8).
macOS: `NSEvent.keyCode`, which identifies the physical key on every layout. Qt reports it as the native
virtual key.

</section>

### VirtualKey Property

Gets the virtual key.

```csharp
public Nullable<uint> VirtualKey { get; set; }
```

#### Remarks

Win32: the virtual-key code.
X11 and Wayland: the keysym.
macOS: null, because macOS has no layout-dependent key code. See [Avalonia.Input.PlatformKeyInfo.ScanCode](xref:Avalonia.Input.PlatformKeyInfo.ScanCode).
