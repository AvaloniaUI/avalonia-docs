## Remarks

Handlers are registered once at startup via
[Avalonia.Controls.Documents.TextModel.TextDocumentNodeKind.Register(string,Avalonia.Controls.Documents.TextModel.NodeKindFlags,Avalonia.Controls.Documents.TextModel.INodeKindHandler)](xref:Avalonia.Controls.Documents.TextModel.TextDocumentNodeKind.Register%28System.String%2CAvalonia.Controls.Documents.TextModel.NodeKindFlags%2CAvalonia.Controls.Documents.TextModel.INodeKindHandler%29)
or by the built-in kind initialization. The correct handler is invoked automatically
during snapshot capture, restore, and rendering.

Thread-safety: [Avalonia.Controls.Documents.TextModel.INodeKindHandler.CaptureSnapshot(Avalonia.Controls.Documents.TextModel.TextDocumentNodeKind,int,int,Avalonia.Controls.Documents.RichTextElement,Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode,Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNodeChildren)](xref:Avalonia.Controls.Documents.TextModel.INodeKindHandler.CaptureSnapshot%28Avalonia.Controls.Documents.TextModel.TextDocumentNodeKind%2CSystem.Int32%2CSystem.Int32%2CAvalonia.Controls.Documents.RichTextElement%2CAvalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode%2CAvalonia.Controls.Documents.Serialization.Snapshot.SnapshotNodeChildren%29) is called on the UI thread during
snapshot creation. The [Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode](xref:Avalonia.Controls.Documents.Serialization.Snapshot.SnapshotNode) it returns is stored on the
[Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot](xref:Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot) and may be read from background threads by
serializers. Return only immutable or thread-safe snapshot nodes.
