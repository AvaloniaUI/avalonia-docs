```csharp
public Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot CreateSnapshot()
```

#### Returns

[Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot](xref:Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot)

A [Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot](xref:Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot) that can be serialized from any thread.


#### Remarks

The snapshot captures text content (O(1) — references immutable rope nodes),
tree structure (O(n) — copies node tree), and formatting (O(n) — value types).

Create a single snapshot and pass it to multiple serializers to avoid
redundant tree traversals:

```csharp
var snapshot = document.CreateSnapshot();
new RtfSerializer().Serialize(snapshot, rtfStream);
new DocxSerializer().Serialize(snapshot, docxStream);
```

### LoadAsync Method

Loads a document from a stream, parsing off the calling thread.

```csharp
public System.Threading.Tasks.Task<Avalonia.Controls.Documents.FlowDocument> LoadAsync(System.IO.Stream stream, Avalonia.Controls.Documents.Serialization.IDocumentSerializer serializer, System.Threading.CancellationToken cancellationToken)
```

#### Parameters

`stream` System.IO.Stream

The stream to read from.


`serializer` [Avalonia.Controls.Documents.Serialization.IDocumentSerializer](xref:Avalonia.Controls.Documents.Serialization.IDocumentSerializer)

The serializer to use.


`cancellationToken` System.Threading.CancellationToken

Token to cancel the operation.


#### Returns

System.Threading.Tasks.Task&lt;[Avalonia.Controls.Documents.FlowDocument](xref:Avalonia.Controls.Documents.FlowDocument)&gt;

A new [Avalonia.Controls.Documents.FlowDocument](xref:Avalonia.Controls.Documents.FlowDocument) with the loaded content.


#### Remarks

The parse runs on the thread pool; the element tree is then built on the UI thread.
A [Avalonia.Controls.Documents.FlowDocument](xref:Avalonia.Controls.Documents.FlowDocument) and its [Avalonia.Controls.Documents.RichTextElement](xref:Avalonia.Controls.Documents.RichTextElement)s are
[Avalonia.AvaloniaObject](xref:Avalonia.AvaloniaObject)s and bind to the dispatcher of the thread that
constructs them, so a document assembled on a pool thread throws on the first
property read from the UI thread. The dispatch is explicit rather than left to an
ambient [System.Threading.SynchronizationContext](xref:System.Threading.SynchronizationContext), which a console host
or a caller already off the UI thread does not have.

Await it. Blocking on the returned task from the UI thread deadlocks: the wait
occupies the thread the element tree has to be built on. A caller that cannot await
uses [Avalonia.Controls.Documents.FlowDocument.Load(System.IO.Stream,Avalonia.Controls.Documents.Serialization.IDocumentSerializer,System.Threading.CancellationToken)](xref:Avalonia.Controls.Documents.FlowDocument.Load%28System.IO.Stream%2CAvalonia.Controls.Documents.Serialization.IDocumentSerializer%2CSystem.Threading.CancellationToken%29), which
parses on the calling thread.

To stay off the UI thread entirely, skip the element facade: read a
[Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot](xref:Avalonia.Controls.Documents.Serialization.Snapshot.DocumentSnapshot) with the serializer and materialize it with

[Avalonia.Controls.Documents.FlowDocument.TextDocument](xref:Avalonia.Controls.Documents.FlowDocument.TextDocument) carries the
whole document and has no thread affinity; [Avalonia.Controls.Documents.FlowDocument](xref:Avalonia.Controls.Documents.FlowDocument) presents it
