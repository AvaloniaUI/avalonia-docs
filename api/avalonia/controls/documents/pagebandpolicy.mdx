<div className="apiref-page__lead">

The shared rule for which band a page shows, applied by the paged view over the
text model and mirrored by the PDF export over snapshots. Explicit first, then
rules, then the running band: a section's first-page reference on the section's
first page; else the document's [Avalonia.Controls.Documents.PageBandRule.FirstPage](xref:Avalonia.Controls.Documents.PageBandRule.FirstPage) band on page
one, else its [Avalonia.Controls.Documents.PageBandRule.EvenPage](xref:Avalonia.Controls.Documents.PageBandRule.EvenPage) band on even pages; else the
section's running reference, else the document's [Avalonia.Controls.Documents.PageBandRule.Default](xref:Avalonia.Controls.Documents.PageBandRule.Default)
band. A rule without a band for a role does not blank the page: the running band
applies. What resolves to nothing shows nothing.
